## Thesis

> Open-ended, long-horizon agentic search systems have outpaced traditional benchmarks; Mind2Web 2 introduces a 130-task benchmark with an Agent-as-a-Judge framework using tree-structured rubrics to automatically evaluate both correctness and source attribution of complex, time-varying answers.

## Methods

- **Agent-as-a-Judge framework**: Automated evaluation via task-specific judge agents that assess correctness (satisfying task requirements) and attribution (statements verifiably backed by cited sources)
- **Tree-structured rubrics**: Hierarchical decomposition of task goals into leaf-node binary criteria, propagated upward via "gate-then-average" aggregation
  - **Critical nodes**: Mandatory gating conditions; failure zeros the entire parent subtree
  - **Non-critical nodes**: Allow partial scoring via averaging
  - **Sequential nodes**: Enforce logical dependencies; earlier failures short-circuit later steps
- **Tool-augmented verification**: LLM-based Extractor (parses structured info from answers) + Verifier (cross-references claims against source screenshots/text)
- **Self-debug and self-reflection pipeline**: Evaluation scripts auto-generated by LLM, autonomously refined, then validated by human experts
- **130 realistic long-horizon tasks** requiring real-time web browsing and extensive information synthesis

## Key Assumptions

- **Generation-verification asymmetry**: Generating comprehensive answers across dozens of websites is hard; verifying them against predefined rubric constraints is tractable and automatable
- Automated evaluation can reliably catch hallucinations before human review
- Tree-structured rubrics can capture the full complexity of open-ended task evaluation

## Limitations

- **Time-varying tasks**: Current systems struggle without live website interaction; agents hallucinate or produce outdated information
- **Incompleteness**: Systems terminate laborious searches early
- **Invalid attribution**: Agents fabricate URLs without actually accessing pages
- **Synthesis errors**: Information incorrectly combined from otherwise valid sources
- **Benchmark creation cost**: >1,000 hours of expert labor to construct the rubrics
- **Human evaluator fatigue**: Humans suffer cognitive fatigue on long tasks, making careless criteria violations that automated judges successfully avoid
